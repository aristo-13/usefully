# Storage

Both buckets and their policies are created by the migration in [`supabase/migrations`](../supabase/migrations).

## `media` (public)

Images used as cover images and inside article bodies.

- Public URLs (`/storage/v1/object/public/media/...`) so pages and social previews can load them.
- Limit 5 MB; JPEG, PNG, WebP, GIF or AVIF. SVG is not allowed because it can carry scripts.
- Paths: `YYYY/MM/<uuid>.<ext>`, generated by the uploader so names cannot collide or be guessed.
- Each upload is recorded in the `media` table with its dimensions and alt text.
- Only admins can upload, replace or delete files.

## `downloads` (private)

Files offered on download pages.

- Not publicly readable. `/go/<slug>` creates a signed URL valid for 60 seconds, with a `Content-Disposition` header that uses the original file name.
- A storage policy allows visitors to request signed URLs only for files attached to **published** downloads, so files of drafts stay private.
- Limit 50 MB (the default maximum upload size of Supabase projects); any file type.
- Paths: `<uuid>/<sanitized-file-name>`.
- Only admins can upload or delete. Replacing a file in the editor or deleting the download removes the old file.

## Uploads

The dashboard uploads files straight from the browser to Supabase Storage with the editor's session, which avoids server request-size limits. A Server Action then validates and records the file.
